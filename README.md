# E-portfolio - Modèle pour étudiant ingénieur ENSEEIHT

Ce dépôt contient un modèle d'e-portfolio pour un(e) étudiant(e) ingénieur à l'ENSEEIHT.

Fichiers créés :

- `index.html` : page d'accueil (présentation, parcours, projets, compétences)
- `pages/` : pages séparées (`cv.html`, `projets.html`, `parcours.html`, `contact.html`)
- `assets/css/style.css` : styles principaux
- `assets/js/main.js` : petit script pour le menu mobile
- `documents/CV.md` : modèle de CV en markdown

Prévisualisation locale :

Ouvrez `index.html` dans votre navigateur ou exécutez un serveur local (recommandé) :

```powershell
python -m http.server 8000; # puis ouvrir http://localhost:8000
```

Personnalisation : remplacez le texte dans `index.html` et les fichiers du dossier `pages/`.

Besoin d'aide pour générer un PDF, traduire en anglais, ou déployer sur GitHub Pages ? Demandez et je l'ajoute.
